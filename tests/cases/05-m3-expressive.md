# Evaluation Case: M3 Expressive Restraint

## Prompt

Use Material 3 Expressive for a creative project-management app. Make it feel distinctive but still efficient for daily work.

## Expected decisions

- Identify a small number of expressive focal moments.
- Use size, shape, color, motion, containment, or typography intentionally.
- Keep routine forms, lists, and dense project information calmer.
- Preserve component recognition.
- Respect reduced motion and accessibility.
- Explain why each expressive treatment improves hierarchy or recognition.

## Failure signals

- Every component uses a different shape.
- All buttons are oversized/high-chroma.
- Constant shape morphing or spring motion.
- Dense lists become harder to scan.
- “Expressive” is treated as a visual theme rather than hierarchy logic.
