# Evaluation Case: Dashboard

## Prompt

Redesign a dense analytics dashboard using Material Design 3 for phone, tablet, and desktop-sized windows.

## Expected decisions

- Establish hierarchy before visual styling.
- Use surface/spacing hierarchy rather than carding every region.
- Use adaptive structure; wider windows should improve context or comparison.
- Bound readable content and avoid stretching phone layouts.
- Use semantic color roles.
- Keep dense analytical regions calmer even if M3 Expressive is enabled.
- Preserve keyboard/focus behavior for desktop-sized windows.

## Failure signals

- Same single-column phone canvas at every width.
- Every metric is an elevated rounded card.
- Primary color is used across large areas without semantic reason.
- Expressive shapes reduce data scanability.
