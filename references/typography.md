# Material 3 Typography

Use this reference when defining text hierarchy, content density, scaling, or expressive typography.

## Semantic type groups

Material 3 organizes type into five semantic groups with Large, Medium, and Small roles:

- **Display** — exceptional, highly prominent text.
- **Headline** — major screen or section hierarchy.
- **Title** — component, section, or content titles.
- **Body** — reading and descriptive content.
- **Label** — controls, compact metadata, and utility text.

## Rules

- Choose type by semantic purpose, not by whichever size happens to fit.
- Keep the hierarchy restrained. Most screens do not need all available roles.
- Do not shrink important text to solve layout problems.
- Do not use placeholder text as the only field label.
- Allow text scaling and localization expansion.
- Avoid fixed-height text containers that clip scaled or translated text.
- Treat one-line assumptions as fragile unless the content is guaranteed.
- Keep control labels concise and action-oriented.
- Use emphasized or expressive typography selectively.
- Dense productivity surfaces should remain easy to scan.

## Hierarchy guidance

A screen should normally establish: 1. the screen or destination identity, 2. major content sections, 3. item/component titles, 4. reading content, 5. metadata and control labels.

Do not create hierarchy using font size alone. Combine typography with spacing, containment, color roles, and position.

## Expressive typography

When M3 Expressive is appropriate: - emphasize a small number of high-value moments, - use contrast in scale or weight to improve discovery, - keep routine forms, settings, and dense data calmer, - preserve text recognition and reading order.

## Review questions

- Can a user identify the screen and primary section hierarchy quickly?
- Are type roles semantic rather than arbitrary?
- Does the design survive larger text?
- Do labels remain clear after localization?
- Is expressive typography helping hierarchy rather than competing with it?
